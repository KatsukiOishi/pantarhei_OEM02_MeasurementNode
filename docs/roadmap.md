# 作業ロードマップ

## 直近の優先順

1. 発電機の追加測定を行い、開放電圧・過渡電圧・同一条件の I-V 特性を確定する。
2. [BQ25570 採用妥当性評価](Architecture/BQ25570_ASSESSMENT.md)の Go / No-Go 条件に従い、BQ25570 案と高耐圧 Buck 案を比較する。
3. [計測・通信レイヤ 電力収支評価](Architecture/POWER_BUDGET_ASSESSMENT.md)の成立条件に従い、風況と10分平均電力を確認する。
4. BQ25570 案を継続する場合、入力保護回路を 0-40 V / 0-0.5 W で評価する。
5. 電源方式の確定後、[システムアーキテクチャ](Architecture/ARCHITECTURE.md) に基づいて回路図と基板を作成する。
6. [ファームウェア実装方針](Firmware/FIRMWARE_PLAN.md) に基づいて DK 上の先行実装を行う。
7. カスタム board 定義、SHTC3、SAADC、Advertising を実基板で統合する。
8. 評価手順と測定記録形式を `test/` 配下へ追加する。

## 記録方針

- 測定ログは `test/measurements/` に置く。
- 生データ、整形済みデータ、考察は分ける。
- 回路・部品の確定判断には、測定条件と根拠リンクを添える。
- 未確定事項が解決したら、このファイルのブロッカーから削除し、README の確定情報へ反映する。
