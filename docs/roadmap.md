# 作業ロードマップ

## 直近の優先順

1. 発電機の追加測定を行い、開放電圧・過渡電圧・I-V 特性を確定する。
2. BQ25570 周辺のリファレンス回路、抵抗値、MPPT 設定、起動・停止しきい値を計算する。
3. 4.3-4.5V 以下へ制限する低損失入力保護回路を検討する。
4. nRF52840、SHTC3、蓄電電圧 ADC、UART / SWD 端子の論理回路を固める。
5. ファームウェア雛形を作り、SHTC3 測定、キャパシタ電圧取得、Advertising ペイロードを実装する。
6. 受信 USB ドングル側の Advertising スキャナと USB CDC 出力を実装する。
7. 評価手順とログ形式を `test/` 配下へ追加する。

## 記録方針

- 測定ログは `test/measurements/` に置く。
- 生データ、整形済みデータ、考察は分ける。
- 回路・部品の確定判断には、測定条件と根拠リンクを添える。
- 未確定事項が解決したら、このファイルのブロッカーから削除し、README の確定情報へ反映する。
