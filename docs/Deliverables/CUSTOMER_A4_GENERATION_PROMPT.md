# 顧客向けA4資料 生成プロンプト

以下を、文書作成機能を持つGPTへそのまま渡す。あわせて `CUSTOMER_A4_FACT_PACK.md` の内容を添付または貼り付ける。

## プロンプト本文

あなたは、電子回路に詳しくない顧客にも理解できる技術説明資料を作るテクニカルライター兼ドキュメントデザイナーです。

添付する「顧客向けA4資料 事実パック」だけを事実の根拠として、日本語の顧客説明資料を作成してください。事実パック内の「採用」「暫定」「未確定」を厳密に区別し、不足情報を推測で補わないでください。

### 成果物

- A4縦、1ページ
- タイトル: 「小型風力発電BLE温湿度ノード 電源成立性のご説明」
- 用途: 顧客との設計方針・試作評価項目の合意
- 出力可能なら編集可能なDOCXまたはGoogle Docs形式
- 文書ファイルを作れない場合は、A4一枚へ配置できる完成原稿とレイアウト指示をMarkdownで出力

### 必須構成

1. 冒頭に2文以内の結論
2. 左から右へ流れる簡略システムブロック図
3. 「通常運転は成立見込み」を示す主要数値の小さな表
4. 発電不足時の動作を4段階で示すフロー
5. 確定事項と試作確認事項を分けた欄
6. 最下部に責任分界と一次資料を小さく記載

### 必ず掲載する内容

- 風力発電をスーパーキャパシタへ蓄え、エネルギーがある時だけ温湿度をBLE送信する方式
- 基準案は10分周期、1M PHY、0 dBm、Advertising 6回
- 暫定ピーク25 mA、平均約0.10 mW、実機受入上限0.15 mW
- 最低比較点2.016 mWに対する蓄電側回収0.605-1.008 mW、発電中の差0.505-0.908 mW
- 暫定成立条件は最低比較点相当の発電時間率25%以上
- 電圧低下時は4.00 Vで送信抑止、下降時3.58 Vで3.3 Vを停止、上昇時4.09 Vで再起動
- 完全放電から1時間以内の初回送信は未保証
- PC側受信・保存・解析は顧客範囲、回路・基板・センサノード側ファームは当方範囲

### 表現上の制約

- 「動作保証済み」ではなく「設計計算上は成立見込み、試作で確認」と表現する
- 年間余剰電力が保証されるような表現をしない
- BQ25570と入力保護回路を最終確定品として扱わない
- 2.016 mWを最低風速保証値と呼ばない
- 「U」の意味や風速を推測しない
- 完全放電から1時間以内に起動すると表現しない
- 顧客名、会社名、製品型式、ロゴを創作しない
- ローカルファイルパス、リポジトリ内部パス、会話履歴、Issue番号、PR番号を掲載しない
- 技術者向けの内部議論や部品選定の迷いを本文へ持ち込まない

### デザイン

- 白背景を基本とし、紺、緑、グレーを中心とした落ち着いた配色
- 本文は10-11 pt相当、タイトルは18-22 pt相当
- 過度な装飾、写真、グラデーション、立体表現は不要
- ブロック図と低電圧フローを主役にし、長文を避ける
- 「成立見込み」「暫定」「要実測」を色またはアイコンで識別する
- 印刷時に判読できるコントラストを確保する

### 作成後の自己検査

提出前に次を確認し、不適合があれば自分で修正してください。

- A4縦1ページに収まっている
- 数値が事実パックと一致している
- 暫定値を保証値として書いていない
- 顧客範囲と当方範囲が逆になっていない
- ローカルパスや内部管理情報が含まれていない
- 完全放電時と蓄電済みの無風時を混同していない

最終回答では、作成した資料本体だけを提示してください。作業過程の説明は不要です。
