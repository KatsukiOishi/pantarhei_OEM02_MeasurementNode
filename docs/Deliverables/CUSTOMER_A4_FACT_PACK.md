# 顧客向けA4資料 事実パック

## 文書情報

- 提出先: パンタレイ様
- 提出元: 株式会社越後鐵工所

## 1. このファイルの用途

小型風力発電BLE温湿度ノードの顧客説明用A4資料を作成・改訂するための根拠情報である。このファイル自体は顧客提出物ではない。

記載内容は次の3種類に区別する。

- **採用**: 現段階で採用する部品または方針
- **暫定**: 設計計算上の仮定であり、試作評価後に確定する値
- **未確定**: 顧客条件または実測が不足している事項

## 2. A4資料で伝える主旨

風力発電機で得た電力をスーパーキャパシタへ蓄え、一定量のエネルギーが確保できた時だけ温湿度を測定してBLE Advertisingで送信する自立型センサノードを検討している。

現時点の設計計算では計測・通信は成立見込みである。ただし、年間を通した稼働率、完全放電からの起動時間、余剰電力の保証には、設置場所の風況と試作機による実測が必要である。

## 3. システム構成

```text
小型風力発電機
  -> 逆接・過電圧保護（暫定設計）
  -> BQ25570 エナジーハーベスト電源（条件付き採用）
  -> 0.47 F スーパーキャパシタ
  -> 3.3 V Buck電源
  -> nRF52840 BLEモジュール + SHTC3温湿度センサ
  -> BLE Advertising
  -> 顧客側受信システム
```

責任範囲は次のとおりである。

| 範囲 | 担当 |
| --- | --- |
| 発電・保護・蓄電・計測回路、基板、センサノード側ファームウェア | 当方範囲 |
| BLE受信以降のPCソフトウェア、ログ保存、解析 | 顧客範囲 |
| 両者間のBLE Advertisingデータ形式 | 協議して確定 |

## 4. 主要部品と状態

| 機能 | 部品 | 状態と要点 |
| --- | --- | --- |
| エナジーハーベスト電源 | TI BQ25570RGR | 条件付き採用。低電圧始動、MPPT、蓄電管理、3.3 V Buckを内蔵 |
| 蓄電 | Eaton PHV-5R4V474-R | 採用。5.4 V、0.47 Fスーパーキャパシタ |
| BLE・制御 | Raytac MDBT50Q-U1MV2 | 採用。nRF52840搭載、外部アンテナ型 |
| 温湿度 | Sensirion SHTC3 | 採用。低消費電力I2Cセンサ |
| 入力クランプ | TLVH431B + BCP53-16 | 暫定候補。BQ25570入力を約4.0 Vへ制限 |
| 入力保護 | 高耐圧P-MOSFET、TVS候補等 | 過渡波形と低電圧始動を試作評価後に確定 |

BQ25570は量産採用品として確定したものではない。低風速域の回収を優先する案として試作し、高耐圧Buck方式との回収エネルギー比較後に最終判断する。

## 5. 顧客提供データから読み取れる範囲

| 条件 | 記録値 | 扱い |
| --- | ---: | --- |
| 1 kohm負荷での最大電圧 | 18.13 V | BQ25570へ直接入力できない根拠 |
| 1 kohm負荷での最大電力 | 328.7 mW | 高出力域の参考値 |
| 10 ohm負荷での最大電流 | 61.2 mA | 入力保護・クランプ設計の参考値 |
| 電力収支の最低比較点 | 2.016 mW | 1 kohm、原データU=1.7の測定点 |

原データの `U` の定義と風速への換算は未確定である。2.016 mWを最低風速で保証される発電電力とは表現しない。

## 6. 計測・通信の電力評価

### 基準案

- 測定・送信周期: 10分
- BLE: 1M PHY、0 dBm、Advertising 6回
- 計測・送信ピーク: 25 mA暫定
- 平均消費電力: 約0.10 mW暫定
- 実機の受入上限: 0.15 mW

BQ25570 Buckは95 mAまで負荷特性が規定され、最大出力電流は110 mA typである。25 mAの暫定ピークは供給可能な見込みである。

最低比較点2.016 mWに対して総合回収効率を30-50%と仮定すると、蓄電側の回収電力は0.605-1.008 mW、平均0.10 mW負荷との差は0.505-0.908 mWとなる。これは発電中の計算上の余剰であり、年間平均の保証値ではない。

公称0.10 mWを維持するために必要な発電時間率は約10-17%である。受入上限0.15 mWと回収効率30%を同時に考慮した暫定成立条件は、最低比較点相当の発電時間率25%以上とする。

### 発電機側の暫定要求

- 始動電圧: 発電機接続端で負荷時1.5 V以上。現構成のLM66100保証動作下限を考慮した試作評価条件であり、製品保証値は前段込みの実測後に確定する。
- 10分周期: 0.30 J以上/10分。蓄電側受入上限0.15 mW、通常回収効率30%から必要平均発電電力を0.50 mWとして算出する。
- 完全放電からの復帰: 0.47 Fを4.09 Vまで充電する蓄電エネルギーだけで3.93 J必要である。発電機入力は3.93 Jを上回るが、コールドスタート効率とリークが未実測のため保証値は試作で確定する。

### 1時間周期案

1時間ごとに計測してAdvertisingを6回送る場合、暫定平均消費は約76-79 uWであり、通常運転は可能な見込みである。79 uWと通常回収効率30%を用いた発電機側要求は約0.95 J以上/時となる。最低比較点に対する必要発電時間率は約8-13%となる。

ただし、完全放電から1時間以内の初回送信は保証しない。コールドスタートは通常回収より低効率で、大容量スーパーキャパシタでは起動に長時間を要する可能性がある。

## 7. 発電・蓄電電圧不足時の動作

```text
発電電力が負荷より小さい
  -> スーパーキャパシタが不足分を供給
  -> VCAPが4.00 V未満: 計測・送信・不揮発書込みを抑止
  -> VCAPが下降時3.58 V: 3.3 V Buckをハード停止
  -> 発電を待ちながら負荷なしで再充電
  -> VCAPが上昇時4.09 V: Buckを再開しMCUをリセット起動
```

完全放電時は、BQ25570単体でも `VIN_DC >= 0.7 V` の最大コールドスタート規定と十分な入力電力を満たす必要がある。現行前段を含むシステム始動電圧は未確定で、1.5 V以上となる可能性がある。

約1.95 Vの内部低電圧しきい値まで低下すると、BQ25570は蓄電素子をVSTORから切り離す。その後は100 mV級の通常回収では復帰できず、再度コールドスタート条件を満たす発電が必要になる。

## 8. 無風時の蓄電目安

平均消費0.10 mW、公称容量0.47 Fによる計算値である。

| 開始状態 | 送信許可4.00 Vまで | ハード停止3.58 Vまで |
| --- | ---: | ---: |
| 初回起動4.09 V | 約0.5時間 | 約2.6時間 |
| 満充電4.73 V | 約4.2時間 | 約6.2時間 |

これは通常回収へ移行済みの状態から無風になった場合の概算であり、完全放電からの起動時間ではない。スーパーキャパシタの公称リーク13 uAが平均消費の半分以上を占めるため、実セルの個体差と温度依存を測定する。

## 9. 顧客資料で断定してはいけない事項

- 年間を通して余剰電力が保証される
- 完全放電から1時間以内に必ず送信できる
- BQ25570が量産回路として確定している
- 40 V / 0.5 Wが顧客要求として確定している
- 原データの `U` が風速を表している
- 2.016 mWが最低風速で保証される発電電力である
- SMBJ40A、LM66100、TLVH431Bを含む入力保護回路が確定している
- 外部アンテナを含めた最終製品の認証条件が確認済みである

未確定事項は「暫定」「試作評価予定」「顧客条件の確認後に確定」のいずれかで表現する。

## 10. 今後の確認項目

1. 同一風速または回転数での開放電圧、過渡電圧、I-Vカーブ
2. 前段込みの最低コールドスタート電圧、入力電力、起動時間
3. 10分周期と1時間周期の実機平均消費電力
4. 低温・最大送信条件での3.3 V保持
5. スーパーキャパシタのリーク分布と無風継続時間
6. 入力クランプの温度上昇と高耐圧Buck方式との回収比較
7. 設置環境の風速分布、発電時間率、要求無風継続時間
