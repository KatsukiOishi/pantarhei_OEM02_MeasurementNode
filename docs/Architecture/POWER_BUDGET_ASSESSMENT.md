# 計測・通信レイヤ 電力収支評価

## 1. 結論

`TLVH431B` + `BCP53-16` による 4.0 V 暫定クランプ、`BQ25570RGR`、0.47 F スーパーキャパシタ、`MDBT50Q-U1MV2`、`SHTC3` の構成で、10 分周期の温湿度測定と BLE Advertising は実現可能と判断する。

- 瞬時電力: 1M / 0 dBmだけでなく、Coded PHY / +8 dBmを想定した25 mA暫定ピークもBQ25570 Buckの仕様範囲に収まる。
- 平均電力: 初期設定の暫定予算は約 0.10 mW、実機受入上限は 0.15 mW とする。
- 発電中: 最低の実測発電点 2.016 mW に対し、総合回収効率を 30-50% と仮定しても約 0.50-0.91 mW の余剰がある。
- 無風時: スーパーキャパシタの公称リークが支配的で、0.10 mW消費時の稼働時間は開始電圧により約2.6-6.2時間と概算する。

したがって、計測・通信レイヤの電力は足りる。ただし、発電が存在する時間率が未定義なので、年間を通した余剰電力はまだ保証できない。公称0.10 mWには最低実測点相当の発電が約10-17%の時間あれば計算上足りるが、0.15 mWの受入上限と回収効率30%を同時に満たす暫定成立条件は25%以上とする。

## 2. 評価条件

| 項目 | 初期条件 |
| --- | ---: |
| 測定・送信周期 | 600 s |
| BLE | 1M、0 dBm、6 回 |
| 拡張評価 | Coded S=8、+8 dBm |
| ロジック電源 | 3.3 V |
| 蓄電範囲 | 4.73 V 以下、3.58 V で負荷停止 |
| 通信許可 | `VCAP >= 4.00 V` |
| スーパーキャパシタ | 0.47 F、ESR 0.4 ohm max |
| 発電の最低比較点 | 2.016 mW |

発電の最低比較点は[客先発電量データ](../客先資料/大石さん送付用_発電量_20260824.csv)の 1 kohm、`U（原データ）=1.7` における測定値である。`U（原データ）` の定義と風速換算が不明なため、これは最低風速保証ではない。

## 3. 瞬時電力

### 3.1 負荷ピーク

| 負荷 | 一次資料の値 | 設計上の扱い |
| --- | ---: | ---: |
| nRF52840 TX、1M / 0 dBm、DC/DC | 6.4 mA typ | 初期設定 |
| nRF52840 TX、1M / +8 dBm、DC/DC | 16.4 mA typ | 最大送信条件 |
| nRF52840 CPU、64 MHz / Flash、DC/DC | 3.3 mA typ | TXと重なる側で加算 |
| SHTC3、低電力測定 | 0.57 mA max | 測定中のみ |
| 設計ピーク | - | 25 mA |

BQ25570 Buckは最大出力電流110 mA typ、サイクルごとのインダクタ電流制限160 mA minであり、データシートの負荷レギュレーションも95 mAまで規定されている。25 mA暫定ピークは規定された負荷範囲の約26%である。SHTC3測定とBLE送信を直列に実行すれば、実際の同時ピークはさらに小さくなる。

スーパーキャパシタ側の電流を 30 mA としても、ESR 0.4 ohmによる瞬時降下は約 12 mV である。BQ25570直近の `COUT >= 22 uF` とモジュール直近のデカップリングを実装すれば、無線ピークが原因となる蓄電電圧低下は支配的ではない。

### 3.2 瞬時電力の判定

瞬時電力は **成立見込み** とする。実機では `VSTOR=3.58 V` 付近、+8 dBm、Coded PHY、低温の最悪条件で、3.3 V出力が許容下限を割らないことを確認する。

## 4. 10分周期の平均電力

### 4.1 暫定予算

| 消費要素 | 仮定 | 蓄電側換算 |
| --- | --- | ---: |
| スーパーキャパシタ自己放電 | 13 uAを4.0 Vでも維持すると仮定 | 52 uW |
| BQ25570動作電流 | 0.9 uA max、4.0 V | 3.6 uW |
| nRF52840待機 | RTC動作 1 uA typ、Buck効率85% | 3.9 uW |
| SHTC3 Sleep | 0.6 uA max、Buck効率85% | 2.3 uW |
| VCAP測定分圧 | 4.7 Mohm + 4.7 Mohm、4.0 V | 1.7 uW |
| 基板リーク・誤差余裕 | 暫定 | 10 uW |
| 計測・1M送信6回 | 1サイクル10 mJ上限、600 s周期 | 16.7 uW |
| **合計** | - | **約 90 uW** |

1サイクル10 mJはデータシート値ではなく、起床、SAADC、SHTC3、NVS書込み、BLE送信6回を含む保守的な設計枠である。Coded PHY / +8 dBm評価では20 mJを暫定上限とし、平均約 0.11 mWとなる。部品ばらつきと未計上リークを含め、実機の受入上限を 0.15 mW とする。

公称13 uAのスーパーキャパシタ自己放電が平均電力の半分以上を占める。通信回数を減らすより、実セルのリーク分布と温度依存性を確認する方が効果が大きい。

## 5. 発電電力と余剰

### 5.1 発電機側の暫定要求

完全放電からの始動について、BQ25570単体の入力条件は `VIN_DC >= 0.7 V`（コールドスタート電圧の最大規定値）である。ただし、現構成は保証動作下限1.5 VのLM66100を前段に含むため、発電機接続端では**負荷時1.5 V以上**を暫定要求とする。これは製品としての始動保証値ではなく、前段回路を含む試作で確定する最低評価条件である。

通常回収時の発電機側エネルギー要求は、蓄電側の受入上限0.15 mWと総合回収効率30%から次のように求める。

- 必要平均発電電力: `0.15 mW / 0.30 = 0.50 mW`
- 10分周期: `0.50 mW * 600 s = 0.30 J/10分`
- 1時間周期: 蓄電側79 uWを上限として `79 uW / 0.30 * 3600 s = 0.948 J/h`、丸めて `0.95 J/h`

完全放電からロジック起動電圧4.09 Vまで充電する場合、0.47 Fスーパーキャパシタへ蓄える理論エネルギーは `0.5 * 0.47 F * 4.09^2 = 3.93 J` である。発電機が供給すべき入力総エネルギーは少なくとも3.93 Jを上回る。コールドスタート効率、前段損失、充電中のリークが未実測であるため、入力総エネルギーの保証値は試作前には定めない。

### 5.2 最低の実測点との比較

最低の実測発電電力 2.016 mWに対し、入力保護、BQ25570 Boost、蓄電、Buckを含む総合回収効率を未実測のため30-50%と仮定する。

| 総合回収効率 | 蓄電側回収電力 | 0.10 mW負荷との差 | 10分当たりの余剰エネルギー |
| ---: | ---: | ---: | ---: |
| 30% | 0.605 mW | 0.505 mW | 0.303 J |
| 50% | 1.008 mW | 0.908 mW | 0.545 J |

最低実測点相当の発電が連続するなら、計測・通信負荷に対して約5-9倍の余剰がある。間欠発電として均すと、公称0.10 mWに必要な発電時間率は約17%（効率30%）から約10%（効率50%）である。受入上限0.15 mWと回収効率30%を同時に満たすには約25%必要となるため、暫定要求は25%以上とする。

### 5.3 中高出力域

4.0 Vクランプ後の50% MPPTでは、BQ25570入力は約2.0 Vを目標とする。既存データからの最大ケース概算では BQ25570入力へ約116 mWが供給可能であり、計測・通信の平均約0.10 mWより3桁大きい。

ただし、これは利用可能な余剰であって、すべて蓄電できるわけではない。スーパーキャパシタ満充電時はBQ25570が充電を停止し、最大ケース概算では4.0 Vクランプが約53 mA、約0.21 Wを熱として処理する。シャント回路の定格と温度上昇を別途確認する。

### 5.4 余剰電力の判定

- 発電中の余剰: 存在する見込み。
- 年間平均の余剰: 風速分布と発電時間率がないため未確定。
- 追加機能へ割り当て可能な保証電力: 現時点では0 Wとし、固定的な追加負荷を設けない。
- 実機評価後の目安: 最低実測点と25%発電時間率を保証できれば、追加負荷を含む平均電力を0.15 mW以内に維持する。

余剰は常時負荷へ割り当てず、`VCAP`が高い場合の追加Advertisingや診断動作など、停止可能な処理へ使用する。

## 6. 無風時の蓄電余裕

スーパーキャパシタのエネルギーを `E = 0.5 * C * (Vhigh^2 - Vlow^2)` で概算する。

| 電圧範囲 | 利用可能エネルギー | 70 uW時 | 100 uW時 | 意味 |
| --- | ---: | ---: | ---: | --- |
| 4.09 Vから4.00 V | 0.171 J | 0.7 h | 0.5 h | 初回起動直後から通信許可下限まで |
| 4.09 Vから3.58 V | 0.919 J | 3.6 h | 2.6 h | 初回起動直後から負荷停止まで |
| 4.73 Vから4.00 V | 1.498 J | 5.9 h | 4.2 h | 満充電から通信許可下限まで |
| 4.73 Vから3.58 V | 2.246 J | 8.9 h | 6.2 h | 満充電から負荷停止まで |

現行の `VCAP >= 4.00 V` は、無風時の送信失敗を避ける保守的なしきい値として成立する。一方、4.09 Vで初めて起動した直後に風が止まると、10分周期で送信できるのは概算3回程度である。

実機の最大送信条件で電圧降下を測定し、十分な余裕が確認できた場合は、通信許可下限を3.7 V付近まで下げることを検討する。設定変更前に、3.3 V Buckのドロップアウト、`VBAT_OK`下降誤差、低温時ESRを含めて確認する。

上表はBQ25570が通常回収へ移行済みの蓄電状態に対する概算であり、完全放電からの起動時間には適用しない。BQ25570のコールドスタート回路は主Boostより低効率で、TIの入力電力計算では最悪効率の見積りに5%を使用している。データシートも、大容量でリークのあるスーパーキャパシタでは初期充電が長くなり、コールドスタートと主Boostの間を段階的に反復し得るとしている。したがって、完全放電から1時間以内の初回送信は現時点で成立と判定せず、前段を含む実測で決める。

## 7. 成立条件と実機試験

次を満たした場合に計測・通信レイヤを正式に成立と判定する。

1. 1M / 0 dBm / 6回の1サイクルエネルギーが10 mJ以下である。
2. Coded S=8 / +8 dBmの1サイクルエネルギーが20 mJ以下である。
3. 10分周期の平均蓄電側消費が0.15 mW以下である。
4. `VSTOR=3.58 V`付近の最大送信時に3.3 V出力が3.2 Vを下回らず、リセットしない。
5. 最低入力条件の蓄電側回収電力が0.60 mW以上である。
6. 要求設置環境で最低入力条件相当の発電時間率が25%以上、または同等のエネルギー収支を満たす。
7. 満充電時のシャント温度が部品定格と基板温度上限を満たす。
8. 無風継続時間の要求が上表の概算範囲内、または要求に合わせて蓄電容量を再選定する。
