# システムアーキテクチャ

## 1. 適用範囲

小型 DC 風力発電機から電力を回収し、温湿度と蓄電電圧を BLE Advertising で送信する初号評価基板の構成を定義する。PC 側ソフトウェアは顧客範囲であり、本書では無線で引き渡すデータまでを境界とする。

BLE、センサ、蓄電素子は本書の品種を初号機へ採用する。電源 IC とその入力保護段は、未測定の発電機 I-V 特性、最大開放電圧、過渡電圧を確認してから確定する。

## 4. 電源設計値

### 4.1 設計エンベロープ

| 項目                       |                初号機の設計値 |
| -------------------------- | ----------------------------: |
| 通常回収開始入力           |                      約 1.8 V |
| 発電機開放電圧             |               40 V 以下、暫定 |
| 最大発電電力               |              0.5 W 以下、暫定 |
| BQ25570 入力クランプ       | 4.0 V 目標、暫定              |
| スーパーキャパシタ充電停止 |                     約 4.72 V |
| ロジック起動               |                     約 4.09 V |
| ロジック停止               |                     約 3.58 V |
| ロジック電源               |                     約 3.30 V |

客先測定では 1 kohm 負荷で最大 18.13 V、328.7 mW、10 ohm 負荷で最大 61.2 mA が記録されている。18.13 V は開放電圧ではないため、40 V / 0.5 W は安全側の暫定条件であり要求値ではない。

### 4.2 BQ25570 設定抵抗

`VBIAS = 1.21 V`、各分圧抵抗合計をおおむね 13 Mohm とし、初号機では以下を実装する。高抵抗ノードはフラックス残渣の影響を受けるため、洗浄と実測を必須とする。

| 設定           | 抵抗値                               |  計算結果 |
| -------------- | ------------------------------------ | --------: |
| `VBAT_OV`      | `ROV1=4.99 Mohm`, `ROV2=8.00 Mohm`   | 約 4.73 V |
| `VBAT_OK` 下降 | `ROK1=3.83 Mohm`, `ROK2=7.50 Mohm`   | 約 3.58 V |
| `VBAT_OK` 上昇 | 上記 + `ROK3=1.62 Mohm`              | 約 4.09 V |
| `VOUT`         | `ROUT1=4.75 Mohm`, `ROUT2=8.20 Mohm` | 約 3.30 V |

抵抗は 0.1% を優先する。`VBAT_OK` を `VOUT_EN` へ接続し、蓄電不足時にロジックをハードウェアで切り離す。

### 4.3 MPPT

DC モーターを内部抵抗を持つ電圧源とみなした初期値として `VOC` の 50% を採用する。基板上の 3 ピン設定で 50%、80%、外付け抵抗設定を選べるようにする。50% は確定した最大電力点ではなく、追加 I-V 測定後に更新する調整初期値である。

前段を4.0 Vでクランプすると、BQ25570がサンプルする `VOC` も約4.0 Vに制限され、50%設定では約2.0 Vを追従する。客先データから概算した中高出力域の最大電力点は約8-13 Vであり、現行案では回収電力を大きく失う可能性がある。詳細と採用条件は[BQ25570 採用妥当性評価](BQ25570_ASSESSMENT.md)に従う。

### 4.4 入力保護

以下は BQ25570 案を継続する場合の暫定構成である。

1. 100 V P-MOSFETで正極側の逆接を保護する。ゲートには 8.2-10 V の VGS 保護を入れる。
2. `SMBJ40A` は 40 V を超える粗い過渡用とし、BQ25570 の 5 V 保護には使わない。
3. `TLVH431B`、`BCP53-16`、33 ohm / 1 Wで約4.0 Vの能動シャントを構成する。設定抵抗、REF入力電流、温度を含む最悪値で `VBAT_OV - VIN_DC >= 0.4 V` を保証する。
4. クランプ後の `LM66100` は低電圧始動への影響と実際の逆流量を比較し、実装またはDNPを決める。
5. BQ25570 直前に 4.7 ohm と 4.7 uF を置き、配線インダクタンスによるオーバーシュートを抑える。
6. 発電入力、クランプ後、`VIN_DC`、`VBAT`、`VOUT` にテストポイントを置く。

能動シャントは 0-40 V の電圧掃引、0-0.5 W の電力掃引、開放・短絡・極性反転、立上り過渡で検証する。全条件で `VIN_DC < 5.1 V`、部品接合温度と抵抗表面温度が定格内であることを確認する。

### 4.5 発電・蓄電電圧不足時の動作

発電機入力の不足とスーパーキャパシタ電圧の不足は、別の状態として扱う。

| 状態 | 電源回路の動作 | 計測・通信レイヤ |
| --- | --- | --- |
| 完全放電、入力不足 | BQ25570単体では `VIN_DC >= 0.7 V`（最大規定値）とコールドスタートに必要な入力電力を満たさない限り、`VSTOR` は上昇しない | 3.3 Vは出力されず停止を維持する |
| コールドスタート成立 | 低効率のコールドスタート回路が `VSTOR` を1.6-1.9 Vまで充電し、その後に主Boostへ移行する | `VBAT_OK` はLowのままで、負荷は起動しない |
| 通常回収、入力電力が負荷以上 | 主Boostが100 mV以上の入力から回収し、スーパーキャパシタを充電または維持する | `VCAP` が上昇時4.09 Vを超えるとBuckが有効になり、MCUが起動する |
| 通常回収、入力電力が負荷未満 | 不足分をスーパーキャパシタから供給し、`VCAP` が徐々に低下する | 3.3 Vは直ちには低下せず、蓄電中の処理を継続できる |
| `VCAP < 4.00 V` | Buckはまだ有効だが、蓄電余裕が少ない | ファームウェアが計測・送信を省略し、待機へ戻る |
| `VCAP` 下降時3.58 V | `VBAT_OK` がLowとなり、直結した `VOUT_EN` がBuckを無効化する | 3.3 Vが遮断され、MCUとSHTC3は停止する |
| 再充電 | 負荷を切り離したまま主Boostが蓄電を継続し、上昇時4.09 VでBuckを再度有効化する | MCUはリセットから起動し、継続実行ではなく新しい起動として扱う |
| 長期入力断 | 約1.95 Vの内部 `VBAT_UV` でVBAT-VSTOR間の内部PFETを開き、蓄電素子の過放電を抑止する | 3.3 Vはすでに停止している |

`VBAT_OK` の4.09 V / 3.58 Vヒステリシスにより、入力電力が瞬間的に不足しても3.3 Vが細かくON/OFFすることを避ける。4.09 Vから3.58 Vまでの蓄電エネルギーは公称容量で約0.92 Jあり、暫定10-20 mJの1回処理より十分大きい。

蓄電電圧が内部 `VBAT_UV` まで低下してVBAT-VSTOR間が開いた後は、100 mV級の通常回収条件では復帰できない。VSTORを主Boost開始電圧まで上げるため、再びコールドスタート電圧と必要入力電力を満たす発電が必要になる。

ただし、完全放電時の0.7 VはBQ25570単体の最大コールドスタート電圧であり、現行前段を含むシステム保証値ではない。データシートの15 uW typも100 uF蓄電素子での試験値である。`LM66100` の保証動作下限1.5 V、P-MOSFETの低電圧特性、能動シャントのリーク、0.47 Fスーパーキャパシタのリークにより、実際の始動電圧、必要入力電力、起動時間は増加し得る。完全放電から1時間以内の初回送信は保証しない。

すべてのシステム負荷はBuckの `VOUT` 側へ接続する。`VSTOR` へ直接負荷を接続すると3.58 Vで切り離されず、再充電不能やコールドスタート反復の原因になる。実機では入力の低速掃引と瞬断を行い、4.09 Vでの起動、4.00 Vでの送信抑止、3.58 Vでの停止、再充電後の再起動に発振やリセット反復がないことを確認する。

## 5. ロジック回路

10分周期、1M / 0 dBm / 6回送信の平均消費電力は約0.10 mWと暫定評価する。25 mAの計測・送信ピークはBQ25570 Buckの能力内である。成立条件、余剰電力、無風時稼働時間は[計測・通信レイヤ 電力収支評価](POWER_BUDGET_ASSESSMENT.md)に従う。

- MDBT50Q-U1MV2 は 3.3 V を `VDD` 系へ供給し、Raytac 仕様書 8.3 の 3.6 V 未満向け構成を踏襲する。
- 32 MHz 水晶と RF 用部品はモジュール内蔵とし、外付けしない。
- 32.768 kHz は初号機で実装・DNPを選べるランドを用意する。未実装時は内部 RC を使用する。
- SHTC3 は 3.3 V、I2C、100 nF デカップリングとし、電源・発熱部から離して基板端へ置く。
- キャパシタ電圧は 4.7 Mohm / 4.7 Mohm と 100 nF の分圧を SAADC へ入れる。入力リークと実装抵抗を含めて校正する。
- UART は GND、3V3_EXT、TX、RX、WAKE、STATUS の 6 ピン。TX/RX に 100 ohm 直列抵抗を置く。
- SWDIO、SWDCLK、RESET、GND、VTref を 10 ピン Cortex Debug または Tag-Connect 互換ランドへ出す。
- 通常動作 LED は搭載しても DNP を標準とし、点灯電流を常時消費しない。

## 6. 基板配置条件

- u.FL とアンテナ同軸はスイッチングノード、発電機配線、スーパーキャパシタから離す。
- Raytac 指定の RF keep-out とモジュール下面パッド条件を守る。
- SHTC3 は BQ25570、インダクタ、シャント抵抗、BLE モジュールから熱的に離し、必要に応じて周囲スリットを設ける。
- `LBOOST`、`LBUCK`、入力・出力コンデンサの高 di/dt ループを最短にする。
- 高抵抗分圧ノードはスイッチングノードから離し、ガードと洗浄性を考慮する。

## 7. 選定確定前の確認事項

- 発電機の最大開放電圧、過渡ピーク、極性反転有無
- 回転数または風速ごとの I-V カーブと最大電力点
- 40 V / 0.5 W 暫定エンベロープの妥当性
- アンテナの実装位置、同軸長、筐体条件
- Coded PHY 使用時にも Raytac の日本向けモジュール認証条件を維持できるかのメーカー確認
- 結露、防水、正式動作温度、通信距離の検収条件

発電機の最大電力点が BQ25570 の入力範囲を超え、回収損失を要求上許容できない場合は、高耐圧 Buck 型または二経路の電源方式へ変更する。蓄電素子も変更後の充電方式との適合性を再確認する。BLE モジュールと SHTC3 の選定は維持する。
