# Codex 対話記録

## 2026-09-03 電源前段と計測・通信の電力収支

### 決定

- BQ25570案では `TLVH431B` + `BCP53-16` の能動シャントを継続候補とする。
- BQ25570入力クランプは、`VBAT_OV - VIN_DC >= 0.4 V` を満たさない4.45 V案を撤回し、4.0 Vを暫定値とする。
- 10分周期、1M / 0 dBm / 6回送信は、平均約0.10 mW、実機受入上限0.15 mWで評価する。
- 計測・通信の25 mA暫定ピークはBQ25570 Buckで供給可能と判断する。
- 最低実測発電点が連続する場合は余剰があるが、年間余剰は風況測定まで未確定とする。公称0.10 mWの必要発電時間率は10-17%、受入上限0.15 mWを含む暫定成立条件は25%以上とする。

### 保留

- `LM66100` は入力定格のため発電機端子の単独逆接保護には使えない。クランプ後の逆流防止として実装するかDNPとするかは実測で決める。
- `SMBJ40A` はBQ25570や40 V LDOを直接保護できるクランプ電圧ではない。入力端のランドを残し、過渡測定後に型式と実装要否を決める。
- 高耐圧LDOはBQ25570前段のクランプではなく、BQ25570を使わない別電源方式として比較する。
- 通信許可下限4.00 Vは、低電圧時の最大送信試験後に3.7 V付近まで下げられるか確認する。

### 次の確認

- 同一風速でのI-Vカーブ、開放電圧、過渡電圧を測る。
- 前段込みの蓄電電力とシャント温度を測る。
- 1M / Coded PHYそれぞれの1サイクルエネルギーと10分平均電力を測る。
- スーパーキャパシタのリーク分布と無風時の通信継続時間を測る。

## 2026-09-03 発電・蓄電電圧不足時の動作

### 電圧不足時の決定

- 発電電力が負荷を下回った場合は、スーパーキャパシタが不足分を供給する。
- `VCAP < 4.00 V` ではファームウェアが計測、送信、NVS書込みを開始しない。
- `VCAP` 下降時3.58 Vでは `VBAT_OK` から `VOUT_EN` をLowにしてBuckを停止し、ロジックをハードウェア遮断する。
- 再充電で上昇時4.09 Vへ達した場合は、MCUをリセットから再起動する。
- システム負荷はBuck出力側に限定し、`VSTOR` へ直接接続しない。
- 内部 `VBAT_UV` 約1.95 Vまで低下した後の復帰には、再度コールドスタート条件を満たす発電が必要になる。
- 完全放電から1時間以内の初回送信は、コールドスタート試験が終わるまで保証しない。

### 電圧不足時の保留

- BQ25570単体のコールドスタート条件は `VIN_DC >= 0.7 V`（最大規定値）だが、前段を含むシステム始動電圧は未確定である。
- 3.58 V付近の最大送信負荷で3.3 V出力を維持できるかは実測前である。

### 電圧不足時の次の確認

- 入力を低速掃引・瞬断し、起動、送信抑止、停止、再起動の各遷移を測定する。
- 最低入力付近でコールドスタート反復や3.3 Vの再起動反復が起きないことを確認する。

## 2026-09-03 顧客向けA4資料の引継ぎ

### 引継ぎ方針

- 別GPTへ渡す情報は自己完結させ、ローカルファイルやリポジトリへのアクセスを前提にしない。
- 顧客提出物にはローカルパス、Issue、PR、会話履歴などの内部管理情報を掲載しない。
- 採用、暫定、未確定を区別し、試作前の計算値を保証値として表現しない。
- 完全放電時と蓄電済みの無風時を区別し、完全放電から1時間以内の送信を保証しない。
- 回路・基板・センサノード側ファームを当方、BLE受信以降のPCソフトウェアを顧客範囲として記載する。

### 方針変更

- 別GPT向けプロンプトの引継ぎから、A4縦2ページの顧客向け企画書を直接作成する方針へ変更した。
- PDFを提出正本、HTMLを編集・印刷用正本とし、draw.io正本から書き出した画像を掲載する。

### 提出情報

- 提出先はパンタレイ様、提出元は株式会社越後鐵工所とする。
- 顧客向け企画書の両ページへ提出先・提出元を明記する。

### 発電機側の暫定要求

- 現構成での始動評価条件は、発電機接続端で負荷時1.5 V以上とする。BQ25570単体の0.7 V最大規定値とは区別し、製品保証値は前段込みの実測後に確定する。
- 10分周期は0.30 J以上/10分、1時間周期は約0.95 J以上/時を発電機側の通常運用要求とする。いずれも総合回収効率30%の保守値である。
- 完全放電から4.09 Vまでの蓄電エネルギーは最低3.93 Jである。コールドスタート効率を通常回収効率で代用せず、発電機入力総エネルギーは試作で確定する。
